# Paper

`normal-modes-of-the-market.pdf` is the compiled working paper.

Build from source (after `scripts/run_study.py` and `scripts/make_macros.py`):

```bash
cd paper
latexmk -pdf main.tex
cp main.pdf normal-modes-of-the-market.pdf
```

`figures/`, `tables/` and `numbers.tex` are generated by the scripts; do not edit them by hand.
